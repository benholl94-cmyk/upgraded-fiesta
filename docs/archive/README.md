# Archive — Datierte Einmal-Dokumente

Hier landen Dokumente, die einen einmaligen Vorfall oder ein Datum
beschreiben und nicht weitergepflegt werden:

- `2026-07-27-branch-cleanup.md` — welche Branches an welchem Tag
  aus welchem Grund geloescht wurden.

Wenn ein neues Datums-Dokument dazukommt, bitte mit `YYYY-MM-DD-prägnanter-name.md`
benennen. Inhaltliche Dokumentation lebt in `docs/` (nicht hier).
